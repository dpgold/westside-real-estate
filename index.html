About the Zillow Home Value Index (ZHVI)

The ZHVI is Zillow's estimate of the typical home value within a given region — not the median sale price. It is calculated from Zillow's Zestimate valuations across all homes in a zip code, not just those that recently sold, which makes it more stable and less susceptible to short-term fluctuations in sales mix.

This dashboard uses the top-tier cut (65th–100th percentile), meaning it tracks the upper segment of the market in each zip code — the higher-value homes, not the middle of the distribution. Values are smoothed and seasonally adjusted to reduce month-to-month noise.

The Relative chart mode re-indexes each zip code to 100% at the start of the selected period, allowing direct comparison of growth rates regardless of absolute price levels — this is where the SPY overlay is most useful, as it lets you compare home appreciation directly against S&P 500 returns. The Actual mode shows raw dollar values (SPY shown in share price). SPY data is the closing price on the first trading day of each month, sourced from Yahoo Finance.
