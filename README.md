# Westside LA Home Value Index

An interactive dashboard tracking top-tier home values across Westside Los Angeles zip codes, using Zillow's ZHVI (Zestimate Home Value Index).

**Live site:** https://westside-real-estate.netlify.app

## Features

- Home value trends over time for four Westside zip codes: Brentwood (90049), Santa Monica (90402), Pacific Palisades (90272), and Malibu (90265)
- Toggle individual zip codes on/off to compare areas
- Summary stat cards with current values and year-over-year changes
- Snapshot table comparing all zip codes at a glance

## Data

- **Source:** Zillow Research — ZHVI (Zestimate Home Value Index), top-tier cut (65th–100th percentile)
- Tracks the upper segment of the market in each zip code, not just recently sold homes
- Values are smoothed and seasonally adjusted
- Single-family homes only
